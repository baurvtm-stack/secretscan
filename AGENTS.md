# Проект: secretscan

CLI-сканер для поиска захардкоженных секретов в исходном коде.

## Стек
- Python 3.11, только стандартная библиотека
- pytest для тестов
- Внешние зависимости запрещены

## Структура
secretscan/
  __init__.py
  rules.py      # правила детекта
  entropy.py    # энтропийный анализ
  scanner.py    # обход файлов, применение правил
  report.py     # вывод: text и json
  cli.py        # точка входа
tests/
  fixtures/     # файлы-приманки с фейковыми секретами
  test_*.py

## Правила
- Код на английском, комментарии на английском
- Type hints обязательны
- Никаких сетевых вызовов
- В фикстурах только заведомо фейковые ключи, никогда не настоящие
- После каждого изменения запускать pytest, коммитить только зелёное
